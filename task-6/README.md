# Task 6 – Full Stack User Management System

A full-stack User Management System developed for Task 6 of the SaiKet Systems Full Stack Development Internship.

## Overview

This task combines frontend and backend development to create a User Management System. Users should be able to add, view, update, and delete their profiles. The frontend displays data provided by the backend and stored in a database.

Authentication is optional and can be added as extra practice.

## Requirements

- Build a frontend interface.
- Build or connect a backend API.
- Connect the backend to a database.
- Allow users to create profiles.
- Display user information from the backend.
- Allow users to update and delete profiles.
- Optionally add login authentication.

## Getting Started

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

Open a separate terminal, navigate to the backend directory, install its dependencies, configure its environment variables, and run the start or development script defined in its `package.json`.

> Backend commands and environment variables depend on the backend implementation. Do not commit secret keys or database credentials.

## Application Workflow

1. A user interacts with the frontend.
2. The frontend sends an HTTP request to the backend.
3. The backend processes the request and communicates with the database.
4. The backend returns a response.
5. The frontend displays the updated data.

## Learning Outcomes

- Understanding full-stack application architecture.
- Connecting a frontend to a backend API.
- Performing CRUD operations.
- Working with a database.
- Handling API requests and responses.
