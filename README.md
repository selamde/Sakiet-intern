# SaiKet Systems – Full Stack Development Internship

A collection of projects completed as part of the **SaiKet Systems Full Stack Development Internship**.

This repository contains six practical tasks covering frontend development, responsive design, frontend frameworks, REST APIs, database integration, and full-stack application development.

## Tasks

| Task | Project | Description |
|---|---|---|
| [Task 1](./task-1/README.md) | Static Portfolio Website | A themed portfolio with project placeholders and a validated contact form. |
| [Task 2](./task-2/nova-store/README.md) | Nova Store | A responsive e-commerce-style webpage with interactive elements. |
| [Task 3](./task-3/README.md) | Front-End Framework Basics | A small task-management app demonstrating framework fundamentals and CRUD interactions. |
| [Task 4](./task-4/README.md) | Basic REST API | A Node.js and Express API for managing users. |
| [Task 5](./task-5/README.md) | Database Integration | Connect a REST API to a relational database to persist user data. |
| [Task 6](./task-6/README.md) | Full Stack User Management | A full-stack application for creating, viewing, updating, and deleting user profiles. |

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/selamde/Sakiet-intern.git
   ```

2. Open the repository:

   ```bash
   cd Sakiet-intern
   ```

3. Open the task folder you want to explore.
4. Follow the setup and run instructions in that task's README.

Each task may have its own dependencies and startup commands. Refer to its individual README before running it.

## Internship Goals

- Build responsive and accessible web interfaces.
- Practice JavaScript and frontend framework fundamentals.
- Design and test RESTful APIs.
- Work with relational databases and SQL.
- Connect frontend, backend, and database layers in a full-stack application.
