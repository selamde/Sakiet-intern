# Task 1 – Static Portfolio Website

A themed, responsive portfolio website created as the first task of the SaiKet Systems Full Stack Development Internship.

## Overview

The objective of this task is to build a personal portfolio website with a homepage, a Projects section containing project placeholders, and a contact form with JavaScript validation.

## Requirements

- Create a homepage to introduce the portfolio owner.
- Add a Projects section to showcase or reserve space for projects.
- Include a contact form.
- Validate form inputs using JavaScript.
- Use Bootstrap or Tailwind CSS for styling.
- Make the website responsive and visually appealing.

## Technologies

- HTML
- CSS
- JavaScript
- Bootstrap or Tailwind CSS

## Features

- Portfolio homepage
- Projects section
- Contact form
- Client-side form validation
- Responsive layout

## Getting Started

1. Open this folder in your code editor.
2. Open `index.html` in a browser.

If the project uses a local development server, start it using the command or extension configured for the project.
