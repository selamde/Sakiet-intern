# Task 3 – Front-End Framework Basics

A small task-management application built to practice the fundamentals of a frontend framework as part of the SaiKet Systems internship.

## Overview

The internship task asks for a small application using React.js or Angular. The example is a to-do list that allows users to add, edit, and delete tasks.

## Requirements

- Learn the basics of React.js or Angular.
- Build a small application.
- Allow users to add tasks.
- Allow users to edit tasks.
- Allow users to delete tasks.
- Demonstrate the framework's core features.
